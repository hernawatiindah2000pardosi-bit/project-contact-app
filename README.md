# Contact Management Application

Aplikasi web berbasis JavaScript murni untuk mengelola data kontak secara dinamis dan efisien. Proyek ini mendemonstrasikan pemahaman mendalam tentang arsitektur front-end tanpa framework pihak ketiga.

## 🌟 Fitur Utama
- **Operasi CRUD Dasar:** Menambah, menampilkan, dan menghapus daftar kontak secara instan.
- **Pencarian Real-Time:** Filter dinamis daftar kontak langsung saat pengguna mengetik kata kunci.
- **Desain Adaptif:** Antarmuka yang bersih dan optimal diakses dari perangkat mobile maupun desktop.

## 🛠️ Teknologi & Konsep yang Digunakan
- **HTML5 & CSS3** (Struktur semen & komponen layout responsif)
- **JavaScript (Vanilla):** Manipulasi DOM, Penanganan Event (*Event Handling*), Array Methods, dan Object Literal.
- **Git:** Manajemen kontrol versi berbasis fitur branch.
